# Development Plan — Code Doctor

## Цель развития

Развитие проекта до уровня middle fullstack PHP-разработчика через практические задачи.

## Архитектурные принципы

- Тонкие контроллеры
- Бизнес-логика в сервисах
- DTO для передачи данных
- Event-driven подход
- Асинхронные задачи через очереди
- Тестирование
- Документирование

## Планируемые модули

### Task Tracker
Управление проектами и задачами внутри команды.

### Site Scan
Автоматическая техническая диагностика сайтов клиентов.

### Toolkit Integration
Вызов Python-инструментов из Laravel.

### REST API
API для фронтенда и внешних сервисов.

### Queues
Асинхронная обработка долгих задач.

### AI Summary
Автоматическое резюмирование технических отчётов.

### Tests
Покрытие критических сценариев.

### Docker
Контейнеризация для локальной разработки и деплоя.
